Write the post in **Markdown**. The file name (without `.md`) becomes the address,
so `my-post-title.md` is served at `/blog/my-post-title`.

Front matter keys: `title`, `date`, `description`, `tags` (comma separated) and
`draft: true` to hide a post while you write it.
